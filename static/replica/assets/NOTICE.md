# Aset acuan untuk replika lokal

Diambil dari halaman publik https://iasc.ojk.go.id/ pada 20 Oktober 2026 untuk reproduksi UI lokal yang diminta pengguna:

- `iasc.png`: https://iasc.ojk.go.id/assets/guest/image/pusaka-logo-text-nov.png
- `pasti.png`: https://iasc.ojk.go.id/assets/guest/image/pasti-logo-text.png
- `hero.jpg`: https://iasc.ojk.go.id/assets/guest/image/main-background.jpg
- `bootstrap.min.css`: https://iasc.ojk.go.id/assets/guest/bootstrap-5.3.7-dist/css/bootstrap.min.css

Identitas dan aset IASC/Satgas PASTI tetap milik pemegang hak masing-masing. Replika ini bukan situs resmi OJK. Bootstrap mempertahankan pemberitahuan lisensi pada berkas CSS. Aset dimuat dari disk lokal saat aplikasi berjalan; tidak ada hotlink ke IASC.
