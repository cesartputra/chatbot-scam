Hybrid intake.

FastAPI + kontrak Pydantic lima tahap. Sesi berlaku selama 60 menit tidak aktif; satu worker. Token sesi adalah rahasia akses sementara.

Alur sesi v1

POST /api/v1/session/init
GET  /api/v1/session/{id}
POST /api/v1/session/{id}/upload
POST /api/v1/session/{id}/chat
POST /api/v1/session/{id}/verify-ekyc
POST /api/v1/session/{id}/submit
GET  /api/v1/session/{id}/status
DELETE /api/v1/session/{id}

Upload multipart: ktp, bukti_transfer, bukti_chat, bukti_rekening_korban. JPG/PNG/WebP maksimal 10 MiB awal per file, dikompresi menjadi <900 kB. PDF tersedia pada kontrak data, tetapi ekstraksi PDF memerlukan adapter tambahan.

Chat: {"text":"email=pelapor.dummy@example.com"} atau {"values":{"tahap1.email_pelapor":"pelapor.dummy@example.com"}}. Konfirmasi: {"confirm":true}.

Konfirmasi & integrasi

POST .../submit
{"setuju_syarat_dan_ketentuan":true,
 "captcha_answer":"jawaban pengguna",
 "integration_mode":"dom"}

Mode dom menghasilkan data dan mapping untuk mengisi replika. Mode webhook memanggil adapter mock lokal, mengembalikan nomor SIM-… dan SIMULATED_NO_BANK_ACTION. Keduanya selalu submitted:false.

Tidak ada e-KYC asli, pemblokiran dana, atau multi-hop tracing. Gateway remote tidak mengganti kegagalan dengan data dummy.
